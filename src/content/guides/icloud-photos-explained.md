## The Big Picture: How It Works

iCloud Photos (The Cloud)
- Every photo/video you take -> uploads automatically
- Syncs to ALL your devices: iPad, iPhone, Mac, iCloud.com
- Originals stored in cloud -> iPad keeps thumbnails
- Private: only YOU (and who you share with) can see

---

## Step 1: Turn On iCloud Photos (One-Time Setup)

1. Open **Settings** -> tap **your name** (Apple ID) at top
2. Tap **iCloud** -> **Photos**
3. Toggle **Sync this iPad** (or "iCloud Photos") -> **ON** (green)
4. Choose **Optimize iPad Storage** (keeps thumbnails, originals in cloud -- **recommended**)
5. Wait for "Uploading..." -> "Updated Just Now" (can take hours/days for large libraries)

> **Cost:** 5 GB free. Most need **50 GB ($1.49/mo)** or **200 GB ($4.49/mo)**. Worth every penny -- auto-backup is priceless.

---

## Step 2: Create Albums -- Your Custom Organization

*Albums are like playlists -- photos stay in "All Photos" but appear in multiple albums.*

### Create an Album
1. Open **Photos** app -> **Albums** tab (bottom)
2. Tap **+** (top-left) -> **New Album**
3. Name it: *"Grandkids 2024," "Family Reunion July," "Medical Records," "Recipes," "House Projects"*
4. Tap **Save** -> select photos -> **Add** (top-right)

### Smart Albums (Auto-Populate)
1. Albums -> **+** -> **New Smart Album**
2. Set rules: *"Date is after Jan 1, 2024" AND "Faces includes [Grandchild Name]"*
3. Auto-updates as new matching photos arrive

### Album Ideas for Seniors
| Album Name | Purpose |
|------------|---------|
| Grandkids [Year] | School, sports, milestones -- share with parents |
| Family History | Scanned old photos, labeled by decade |
| Medical | Prescription labels, insurance cards, test results, mole tracking |
| House & Repairs | Before/after, appliance models, paint colors, contractor info |
| Recipes | Photos of handwritten cards, cookbook pages, successful dishes |
| Travel | Trips, day trips, visited places |
| Favorites | Heart tap on best shots -> auto-adds here |

## Step 3: Share Albums with Family -- They Get Updates Automatically

### Create a Shared Album
1. Albums -> **+** -> **New Shared Album**
2. Name: *"Grandkids for Family"* -> **Next**
3. Add contacts: type names -> select from your Contacts -> **Create**
4. Recipients get **invitation** -> accept -> album appears in *their* Photos app under **Shared**

### What Shared Albums Do
| Feature | How It Works |
|---------|--------------|
| Auto-sync | You add -> they see instantly (Wi-Fi) |
| Comments | Family comments on photos -> you get notification |
| Download | They can save to their library |
| No storage cost | Shared albums don't count against *their* iCloud |
| Up to 100 people | Whole family + cousins + friends |

> **Pro tip:** Create **one** shared album per family unit (kids, grandkids, siblings) -- not per event.

## Step 4: Find Photos Fast -- Search Like Magic

**Photos app -> Search (magnifying glass, bottom-right)**

| Search For | Example |
|------------|---------|
| **Person** | "Sarah" (after you name faces -- see below) |
| **Place** | "Ottawa," "Cottage," "Florida" |
| **Date** | "December 2023," "Last Tuesday," "2 years ago" |
| **Category** | "Beach," "Dog," "Food," "Sunset," "Car," "Document" |
| **Text in photo** | "Prescription," "Recipe," "Serial number" (Live Text) |
| **Combination** | "Sarah beach 2023" -> Sarah at beach in 2023 |

### Name Faces (Teaches Search Who's Who)
1. Photos -> **Albums** -> **People & Pets** (under "Other")
2. Tap unnamed face -> **Add Name** -> type name -> **Next** -> **Done**
3. Confirm suggested matches -> **Done**
4. Now search "Frank" -> every photo of Frank appears

## Step 5: Free Up iPad Space -- Keep Photos, Lose the Bulk

**If "iPad Storage Full" -> Settings -> General -> iPad Storage -> Photos**

### Enable "Optimize iPad Storage" (Already in Step 1)
- Keeps **thumbnails** on iPad (tiny, instant load)
- **Originals** in iCloud -> download on demand (tap to view full-res)
- **Saves 80-95% space** -- 50 GB library -> 2-5 GB on iPad

### Manually Offload (If Still Full)
1. Settings -> General -> iPad Storage -> **Photos**
2. **Enable "Offload Unused Apps"** (separate, but helps)
3. **Review Large Attachments** in Messages -> delete old videos

### Check iCloud Storage
1. Settings -> **Your Name** -> **iCloud** -> **Manage Storage**
2. **Photos** = usually largest
3. **Upgrade** if needed: 50 GB -> 200 GB -> 2 TB (Family Sharing shares 200 GB+)

## Step 6: Scan & Save Paper Photos -- Digitize Your History

### Using Notes App (Built-In Scanner)
1. Open **Notes** -> new note -> **Camera icon** -> **Scan Documents**
2. Position paper photo -> auto-captures -> **Keep Scan** -> **Save**
3. **Markup** -> add text: "Mom & Dad, 1965 wedding"
4. **Share** -> **Save to Photos** -> appears in library -> add to "Family History" album

### Using Files App (For Multi-Page)
1. Open **Files** -> **On My iPad** -> **Downloads** (or create folder)
2. **Three dots** -> **Scan Documents** -> multi-page -> **Save**
3. Share -> **Save to Photos** (each page as image)

> **Pro tip:** Scan at 300 DPI (Notes default). Name files: `1965-wedding-mom-dad.jpg`

## Step 7: Backup Beyond iCloud -- The 3-2-1 Rule

*iCloud is ONE copy. For irreplaceable photos, have THREE.*

| Copy | Where | How |
|------|-------|-----|
| 1. Primary | iCloud Photos | Automatic (Step 1) |
| 2. Local | External SSD / USB drive | Connect to Mac/PC -> Photos -> Export -> Unmodified Original |
| 3. Offsite | Second cloud (Google Photos, Amazon Photos, Backblaze) | Auto-upload from computer |

### Easy Local Backup (Once a Year)
1. Connect iPad to Mac/PC (or use iCloud.com on computer)
2. **Photos app (Mac) / iCloud.com (PC)** -> Select All -> **Export** -> **Unmodified Originals**
3. Save to **external drive** labeled "Photos Backup 2025"
4. Store drive in **different location** (kids' house, safe deposit box)

## Troubleshooting Quick Fixes

| Problem | Solution |
|---------|----------|
| iCloud Photos won't turn on | Check: Wi-Fi, iCloud storage not full, Apple ID signed in, iOS updated |
| Photos not syncing to other device | Same Apple ID? iCloud Photos ON? Wi-Fi? Check "Sync this iPad" on each |
| Shared album not updating | Recipient accepted invite? Their iCloud Photos ON? Wi-Fi? Force-close Photos app |
| Can't find photo I know exists | Search -> try date, place, "document," "screenshot," "recently deleted" |
| Accidentally deleted photo | Albums -> **Recently Deleted** (bottom) -> 30-day recovery -> **Recover** |
| iPad storage still full | Settings -> General -> iPad Storage -> Photos -> **Optimize** ON? Wait overnight |
