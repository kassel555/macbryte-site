## Quick Start: The 3 Most Impactful Changes

| Setting | Path | Why It Helps |
|---------|------|--------------|
| **Larger Text** | Settings -> Display & Brightness -> **Text Size** (drag right) + **Bold Text** ON | Everything readable without glasses |
| **Zoom** | Settings -> Accessibility -> **Zoom** ON -> double-tap 3 fingers to zoom | Magnify anything instantly |
| **Speak Selection** | Settings -> Accessibility -> Spoken Content -> **Speak Selection** ON | Tap text -> "Speak" -> iPad reads aloud |

## Vision Settings

### 1. Display & Text Size -- **Start Here**
**Path:** Settings -> Display & Brightness

| Setting | What It Does | Recommended |
|---------|--------------|-------------|
| **Text Size** | Drag slider right -> larger system text | Max comfortable |
| **Bold Text** | Makes all system text thicker | **ON** |
| **Larger Accessibility Sizes** | Settings -> Accessibility -> Display & Text Size -> **Larger Text** ON -> slider | For very large text |
| **Button Shapes** | Adds outlines to buttons | **ON** |
| **On/Off Labels** | Shows "1" / "0" on toggles | **ON** |
| **Reduce Transparency** | Solid backgrounds, less blur | **ON** |
| **Increase Contrast** | Darker colors, sharper edges | **ON** |
| **Differentiate Without Color** | Uses shapes + color (not color alone) | **ON** |

### 2. Zoom -- **Magnify Anything Instantly**
**Path:** Settings -> Accessibility -> **Zoom** -> ON

| Gesture | Action |
|---------|--------|
| **Double-tap 3 fingers** | Toggle zoom on/off |
| **Drag 3 fingers** | Move around zoomed screen |
| **Double-tap 3 fingers + drag** | Adjust zoom level (1.2x - 15x) |
| **Triple-tap 3 fingers** | Zoom menu (filter, lens, resize) |

> **Pro tip:** Enable **Zoom Controller** (Settings -> Accessibility -> Zoom -> Zoom Controller) -- floating button for one-tap zoom.

### 3. VoiceOver -- **Screen Reader (If Text Too Small Even Zoomed)**
**Path:** Settings -> Accessibility -> **VoiceOver** -> ON

- **Gesture-based**: Swipe right/left = next/previous item, double-tap = activate
- **Speaks everything**: Text, buttons, battery, time, notifications
- **Rotor**: Two-finger twist -> choose Headings, Links, Words, Characters
- **Practice**: VoiceOver Practice (in VoiceOver settings) -- safe sandbox

> **Note:** VoiceOver changes ALL gestures. Only enable if needed. Triple-click side button (Settings -> Accessibility -> Accessibility Shortcut -> VoiceOver) for quick toggle.

### 4. Speak Screen & Speak Selection -- **Read Aloud On Demand**
**Path:** Settings -> Accessibility -> Spoken Content

| Feature | How to Use |
|---------|------------|
| **Speak Selection** | Highlight text -> tap **Speak** |
| **Speak Screen** | Swipe down with **2 fingers from top** -> reads entire screen |
| **Speech Controller** | Floating button: play/pause, speed, skip |
| **Highlight Content** | Words/sentences highlight as spoken |
| **Typing Feedback** | Speak characters, words, auto-text |

> **Great for:** Emails, web articles, Messages, Settings menus, medication labels (photo -> markup -> speak)

### 5. Display Accommodations -- **Color & Light Sensitivity**
**Path:** Settings -> Accessibility -> Display & Text Size

| Setting | Best For |
|---------|----------|
| **Color Filters** | Color blindness (Grayscale, Red/Green, Blue/Yellow) |
| **Reduce White Point** | Screen too bright even at minimum -- dims whites |
| **Auto-Brightness** | Adjusts to ambient light (keep ON) |
| **Reduce Motion** | Stops parallax, app transitions -- reduces dizziness |

## Hearing Settings

### 6. Hearing Devices -- **Pair Hearing Aids Directly**
**Path:** Settings -> Accessibility -> **Hearing Devices**

- **MFi (Made for iPhone) hearing aids**: Pair once -> auto-connect, volume control in Control Center
- **Live Listen**: iPad becomes remote microphone -> streams to hearing aids (great for lectures, TV, noisy restaurants)
- **Audio Routing**: Calls -> hearing aids, Media -> hearing aids, or split

### 7. Audio/Visual -- **Customize Sound**
**Path:** Settings -> Accessibility -> Audio/Visual

| Setting | What It Does |
|---------|--------------|
| **Mono Audio** | Combines stereo -> both ears hear everything (if one ear weaker) |
| **Balance** | Slider: left/right ear volume |
| **Phone Noise Cancellation** | Reduces background noise on calls |
| **Headphone Accommodations** | Custom audio profile (Custom Audio Setup -> 3-min test) |
| **Background Sounds** | Rain, ocean, white noise -- masks tinnitus, aids focus |

### 8. Subtitles & Captioning -- **Always On Option**
**Path:** Settings -> Accessibility -> Subtitles & Captioning

- **Closed Captions + SDH** ON -> shows subtitles in Videos, TV app, supported apps
- **Style**: Large Text, Classic, Create New Style (font, size, color, opacity)

### 9. LED Flash for Alerts -- **Visual Notification**
**Path:** Settings -> Accessibility -> Audio/Visual -> **LED Flash for Alerts** ON

- Camera flash blinks for calls, texts, alarms, timers
- **Flash on Silent** ON -> works even when muted

## Mobility & Touch Settings

### 10. Touch Accommodations -- **If Hands Tremor or Tap Accuracy Is Hard**
**Path:** Settings -> Accessibility -> Touch -> **Touch Accommodations** ON

| Setting | Helps With |
|---------|------------|
| **Hold Duration** | Tap must hold X seconds (0.1-4.0) -- prevents accidental taps |
| **Ignore Repeat** | Multiple rapid taps = one tap (0.1-4.0 sec window) |
| **Tap Assistance** | **Use Initial Touch Location** (where finger first lands) or **Use Final Touch Location** (where finger lifts) |
| **Gesture Delay** | Longer delay for swipe/drag gestures |

### 11. AssistiveTouch -- **Virtual Button for Hardware Difficulties**
**Path:** Settings -> Accessibility -> Touch -> **AssistiveTouch** ON

- Floating button: Home, Siri, Control Center, Notification Center, Device (volume, lock, rotate), Custom gestures
- **Custom Top Level Menu**: 1-8 icons, reorder
- **Dwell Control**: Hover over icon -> auto-activate (with head tracking on newer iPads)

### 12. Switch Control -- **Full iPad Control via Switches**
**Path:** Settings -> Accessibility -> **Switch Control** -> ON

- External switches (Bluetooth), screen tap, camera head tracking, sound (pop/click)
- Scanning: Auto, Manual, Step -- highlights items sequentially
- **Recipes**: Complex actions (scroll, drag, pinch) via single switch

### 13. Voice Control -- **Speak Commands, No Touch Needed**
**Path:** Settings -> Accessibility -> **Voice Control** -> ON

- "Go Home," "Open Mail," "Tap Send," "Scroll Down," "Swipe Left"
- **Overlay**: Numbers on every tappable item ("Tap 12")
- **Grid**: Screen divided -> "Tap grid 3C"
- **Custom commands**: "Text Karen" -> types message
- **Works offline** (download language pack)

## Cognitive & General Settings

### 14. Guided Access -- **Lock to One App (Great for Focus)**
**Path:** Settings -> Accessibility -> **Guided Access** -> ON

- Triple-click side button -> start -> circle areas to disable -> **Start**
- Passcode or Face ID to exit
- **Time Limits**: Sound/voice warning when time nearly up

### 15. Siri -- **Voice Assistant for Everything**
**Path:** Settings -> Siri & Search

| Setting | Recommendation |
|---------|----------------|
| **Listen for "Hey Siri"** | ON (iPad plugged in or newer models) |
| **Press Side Button for Siri** | ON |
| **Allow Siri When Locked** | ON |
| **Voice Feedback** | "Always" or "Control with Ring Switch" |
| **Siri Responses** | "Prefer Spoken Responses" |

> **Senior-friendly commands:** "Call Sarah," "Read my messages," "Set timer 20 minutes," "Remind me pills at 8pm," "What's weather," "Open FaceTime"

### 16. Accessibility Shortcut -- **Triple-Click for Instant Access**
**Path:** Settings -> Accessibility -> **Accessibility Shortcut**

Select 1-6 features -> triple-click side button (or Top button on iPad without Home) -> choose:
- VoiceOver, Zoom, Magnifier, Voice Control, AssistiveTouch, Guided Access, etc.

## Setup Checklist: Do These in Order

1. [ ] **Text Size + Bold** (Display & Brightness)
2. [ ] **Zoom** ON (Accessibility -> Zoom)
3. [ ] **Speak Selection** ON (Accessibility -> Spoken Content)
4. [ ] **Button Shapes + On/Off Labels** (Accessibility -> Display & Text Size)
5. [ ] **Reduce Motion + Increase Contrast** (Accessibility -> Motion / Display)
6. [ ] **Hearing Aids** paired (if applicable)
7. [ ] **Mono Audio + Balance** (if hearing asymmetrical)
8. [ ] **Touch Accommodations** (if tremor/tap issues)
8. [ ] **AssistiveTouch** (if Home button / gestures difficult)
9. [ ] **Accessibility Shortcut** with top 3 features
10. [ ] **Siri** enabled + "Hey Siri" trained
