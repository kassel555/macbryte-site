## What You'll Learn (Customized to Your Goals)

### Getting Comfortable — So Your Computer Feels Familiar, Not Foreign
- Turning on/off, restarting, sleep vs shutdown
- Keyboard & mouse (or trackpad) basics — click, double-click, right-click, drag
- Desktop, taskbar (Windows) / Dock (Mac), Start menu / Launchpad
- Adjusting volume, brightness, text size for comfort

### Files & Folders — So You Always Find What You Save
- Understanding drives: C: (Windows) / Macintosh HD (Mac)
- Creating folders, naming them logically (e.g., "Family Photos," "Medical," "Finances")
- Moving, copying, renaming, deleting files
- **The "Downloads" folder** — where things go, how to clean it
- USB drives & external hard drives: plug in, find, safely eject

### Email Essentials — So You Stay Connected Without the Clutter
- Composing, replying, forwarding, attaching photos/documents
- Understanding Inbox, Sent, Drafts, Spam/Junk, Trash
- Organizing with folders/labels (e.g., "Family," "Medical," "Bills")
- **Spotting phishing** — urgent language, suspicious senders, weird links
- Unsubscribing from unwanted newsletters

### Internet Browsing — So You Find What You Need Safely
- Address bar vs search bar — when to use each
- Bookmarks/favorites for frequent sites (bank, library, weather)
- Tabs: open, close, switch, pin
- **Safe searching** — evaluating results, avoiding ads disguised as links
- Clear browsing history/cookies (and why it matters)

### Updates & Maintenance — So Your Computer Stays Healthy
- Windows Update / macOS Software Update — why "later" becomes "never"
- Restarting regularly (fixes 90% of weird issues)
- Basic security: Windows Defender / macOS Gatekeeper, firewall on
- Backing up: File History (Windows) / Time Machine (Mac) + external drive

### Printing & Scanning — So Paper Documents Don't Pile Up
- Adding a printer (Wi-Fi or USB)
- Printing from email, browser, photos
- Scanning to PDF — medical forms, receipts, letters
- Paperless tip: photograph documents with phone -> email to self

## Frequently Asked Questions

**Do you teach both Mac and Windows?**  
Yes! I coach on both Mac (macOS) and Windows (10/11). Fundamentals are similar — files, folders, email, browser — and I adapt to your system.

**What if I have a laptop vs desktop?**  
Both work the same way. I'll teach trackpad gestures (laptop) or mouse skills (desktop) as needed.

**Can you help me set up a new computer from scratch?**  
Absolutely. Unboxing, user account, Wi-Fi, email, browser, printer, backup — I handle the full setup.

**Do I need to know typing?**  
No. Hunt-and-peck is fine. We can also set up voice dictation (Windows: Win+H, Mac: fn twice) if typing is difficult.

**What if my computer is really old?**  
If it runs Windows 10/11 or macOS 11+, we can work with it. If older, I'll advise on whether it's worth updating or replacing.

**How many sessions for computer basics?**  
Most students need 4–6 sessions for solid foundations. Some want ongoing weekly lessons. Entirely up to you.
